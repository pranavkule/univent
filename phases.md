Phase 1 done: GitHub repo, base folder structure (`apps/web`, `backend/functions`, `infrastructure/template.yaml`), project plan, initial docs.
Phase 2 done: React + Vite prototype on mock data — landing page, events with search/category filters, event details, mock sign-up/sign-in, registration with validation and mock ID confirmation, participant dashboard (own registrations with statuses). Routes: `/`, `/events`, `/events/:id`, `/events/:id/register`, `/confirmation/:id`, `/signup`, `/signin`, `/dashboard`. Mock auth/data isolated in `services/` for later Cognito/API swap; organizer-wide view intentionally out of scope. `npm run build` and preview verified, no AWS yet.
Phase 3 done: `sam validate` and `sam build` passed; all four routes were mounted and exercised with 46 SAM-local checks covering successful and invalid requests, authentication, duplicate registration, and capacity. `npm --prefix backend test` passes (29 tests), and `docs/api.md` documents the API. The development identity headers are enabled only with the explicit local setting and SAM-local marker; deployed Lambda requests ignore them. At that point there was no `package.json` under `backend/functions/` because the handlers used only local modules and Node.js built-ins; Phase 4 adds the DynamoDB SDK dependencies. Storage remained in-memory and process-local in Phase 3; persistence arrives in Phase 4.
Organization workspace (mock frontend, verified via `npm run build`): role-gated `/org` section for approved organization accounts (demo: `codecell@ves.ac.in`) with sidebar layout, summary cards, My Events (search + status filter, edit/submit/cancel), Create/Edit Event form (draft + submit-for-approval with validation), org-scoped Registrations, and Organization Profile (name/description editable; email/approval read-only, Admin-controlled). Mock services in `apps/web/src/services/orgEvents.js` + `organizations.js`, localStorage-backed; the backend was added in Phases 3–5.
Student + Admin interfaces (mock frontend, verified via `npm run build`): `/dashboard` is the student hub (welcome, Upcoming/My/Attended cards, upcoming events, quick links); `/registrations` lists the student's own registrations with status filter and confirm-before-cancel (upcoming events only); `/profile` shows read-only account details; `/events` gains availability filter, date sort, and per-event Registered badges; `/events/:id` and `/events/:id/register` handle full/closed/already-registered states. Role-gated `/admin` section (demo: `admin@univent.demo`) with Overview (6 platform cards, pending queues, recent activity), Organizations (approve/reject-with-reason/suspend/reactivate), Events (platform-wide approve/reject/cancel with reasons), Users (safe fields only, no passwords), and Reports (registrations by event, status distribution, audit-log placeholder). New mock services in `apps/web/src/services/admin.js`; no AWS/Cognito/DynamoDB yet.
Phase 4 done locally: two DynamoDB tables plus owner GSI, atomic registration transaction with fail-closed counters, principal-derived ownership, per-function IAM roles, seed/reconcile scripts, and `UNIVENT_STORE=dynamodb` wiring are implemented. `npm --prefix backend test` passes 48 unit tests, DynamoDB Local integration passes 9/9 with 0 skipped (concurrency, duplicate, readiness, GSI, seed/reconcile, all four handlers), `sam validate --lint` and `sam build` pass, and `apps/web` still builds. No AWS stack was deployed; deployment and live-table seeding remain Phase 7.
Phase 5 done locally: Cognito User Pool/client/groups, exact `@ves.ac.in` PreSignUp trigger, email-code confirmation flow, API Gateway authorizer on the three protected routes, student/organization/admin role enforcement, frontend mock-vs-Cognito auth facade, `/confirm-signup`, and a controlled provisioning script are implemented. `npm --prefix backend test` passes 68/68, `npm --prefix apps/web test` passes 12/12, DynamoDB Local integration remains 9/9 with 0 skipped, `sam validate --lint` and `sam build` pass, and the frontend builds (152 modules). No deploy or live Cognito check has been done yet.
